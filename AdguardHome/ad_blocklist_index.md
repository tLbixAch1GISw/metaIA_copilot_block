### How to Use

- **Hosts/DNS lists**: Direct import into Pi-hole, AdGuard Home, or hosts file.
- **Adblock/Ublock/AdGuard**: Add the filter URL in "Custom Filters" section.
- **Check GitHub pages, as some hosts or lists are split by category or type.**

This index covers diverse threats, languages, and use cases, and should help you find any major or specialized blocklist you need! If you’d like more or have a specific region/type, let me know.
